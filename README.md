# #1 Lavanderia Express Estância Velha

Site oficial e landing page de alta conversão da **#1 Lavanderia Express**, localizada em Estância Velha/RS. Desenvolvido com Astro e CSS moderno.

## 🧺 Sobre a #1 Lavanderia Express

Lavanderia express self-service moderna. Permite lavar e secar roupas do dia a dia, edredons de casal, queen, king e peças volumosas em menos de 1 hora, com sabão e amaciante profissionais inclusos no ciclo, espaço 100% climatizado, TV, Wi-Fi gratuito, café expresso, espaço kids e borrifador de perfume para roupas.
